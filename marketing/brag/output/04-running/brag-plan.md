# Brag Plan: FitSocial run tracking

## Angle
"Every kilometre counts, wherever you ran it." The live run (card map and full-screen map, both on real Durban streets from OpenStreetMap in the app's map colours), treadmill mode, runs imported from Health Connect waiting in Create, and the finish sheet with Save to Photos / Share.

## Tone
cinematic. Vertical 30 s, vol-12 (110 BPM) at 0.36. Scene changes on strong beats 8.74, 13.11, 17.47, 22.93.

## Storyboard
1. 0-3.27 "EVERY KILOMETRE / COUNTS." over the full-screen live map, slow push.
2. 3.27-8.74 "TRACK IT LIVE." Live Run with the map card; tap on expand.
3. 8.74-13.11 "GO FULL SCREEN." full-screen map.
4. 13.11-17.47 "TREADMILL? COVERED." Treadmill Run with "Distance on the display".
5. 17.47-22.93 "WATCH RUNS LAND HERE." Create, "Run we found", 8.42 km, "No route recorded".
6. 22.93-26.7 "SAVE THE CARD." finish sheet scroll to Save to Photos / Share.
7. Wordmark on a bell.

## Claims checked
Health Connect import and "Run we found" (run_drafts_section.dart, RELEASE_NOTES 1.0.0 (9)), treadmill display distance (treadmill_run_screen.dart), Save to Photos/Share (save_run_card_row.dart), full-screen map (live_run_map_screen.dart).
